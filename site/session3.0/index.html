Session 3.0 · Pre-work

Set up an AI agent on your computer before Friday.

In 3.1 you build a knowledge base with an AI agent that works on files on your own computer, so it will not run in Claude or ChatGPT in a web browser. Do this page before class: install one agent, either as a desktop app or in the terminal, and check that it answers. Paperclip, a literature search tool, is optional. It takes about 20 minutes.

Stuck? Email biocore@umassmed.edu → macOS or Windows · Your own computer, with permission to install software

Set up

If anything below fails to install, or your computer does not let you install software, contact us at biocore@umassmed.edu before Friday. We would rather sort it out this week than in class.

Check what you need

  • A paid Claude or ChatGPT subscription. Free plans do not include these agents.
  • One AI agent that can work on a folder on your computer. Pick one of these four:
    • Claude desktop app, using its Code tab
    • ChatGPT desktop app (formerly the Codex app)
    • Claude Code in the terminal
    • Codex CLI in the terminal

Never used a terminal? Pick an app: you click and type in a window like any other program. The terminal versions do exactly the same work, and they are what John uses in class. Both routes work for the whole exercise.

Install your agent

Open the one you picked and follow its steps.

APP Claude desktop app
  1. Download Claude for macOS or Windows from claude.com/download, install it, open it, and sign in.
  2. Click the Code tab at the top. If it asks you to upgrade, your account is not on a paid plan yet.
  3. Windows only: the Code tab needs Git for Windows. Install it with the default options, then restart Claude.
APP ChatGPT desktop app
  1. Download the ChatGPT desktop app from OpenAI’s app page, install it, open it, and sign in with your ChatGPT account. On a Mac it needs Apple Silicon (M1 or newer); on an older Intel Mac, use Codex CLI instead.
  2. Check that you can open a folder on your computer as a project. That is how you will work in class.
TERMINAL Claude Code or Codex CLI

Open a terminal. On macOS, press Cmd+Space, type Terminal, and press Enter. On Windows, click Start, type PowerShell, and press Enter. Paste one line below and press Enter.

Claude Code, macOS:

curl -fsSL https://claude.ai/install.sh | bash

Claude Code, Windows PowerShell:

irm https://claude.ai/install.ps1 | iex

Codex CLI, macOS:

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Codex CLI, Windows PowerShell:

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Then start it: type claude for Claude Code or codex for Codex CLI, press Enter, and follow the login instructions.

Check that it works

App: in the Claude Code tab choose Local and Select folder, or in the ChatGPT app open a folder, and pick any folder (your Documents folder is fine). Terminal: start claude or codex. Then type:

What can I do with coding agents?

Checkpoint The agent answers. If it does, you are ready for Friday. In the terminal, type /exit (Claude Code) or press Ctrl+C twice to leave.

Optional: install Paperclip for literature search

Paperclip is a scientific paper index that gives your agent search and retrieval over more than 8 million papers. It makes the literature steps in 3.1 better, but you do not need it: without it, your agent searches PubMed Central through NCBI instead, with no install and no account. Paperclip installs from a terminal even if you use an app, and it then works in both.

First create a free Paperclip account. Then open a terminal (on macOS, Terminal; on Windows, PowerShell) and install it.

macOS:

curl -fsSL https://paperclip.gxl.ai/install.sh | bash

Windows: Paperclip has no Windows installer yet, so install it with Python.

  1. If you do not have Python, install it from python.org. On the installer’s first screen, tick Add python.exe to PATH. Then close PowerShell and open a new one.
  2. Paste these three lines into PowerShell:
Invoke-WebRequest https://paperclip.gxl.ai/paperclip.whl -OutFile "$env:TEMP\gxl_paperclip-0-py3-none-any.whl"
python -m pip install --no-deps "$env:TEMP\gxl_paperclip-0-py3-none-any.whl"
python -m pip install requests click pyyaml
  1. Close PowerShell and open a new one, so it finds the new paperclip command.
WHY Why three lines instead of one?
The download is a standard Python package, but its file name is too short for Python’s installer to accept, so the first line saves it under a name it will take. The second line installs Paperclip, and the third installs the three packages it needs. This is the same thing the macOS installer does.

Both: set Paperclip up for your agent. It asks you to sign in with the account you just made.

paperclip install

Checkpoint paperclip config shows your email next to Auth. If Paperclip will not install, skip it and let us know at biocore@umassmed.edu; each step in 3.1 that uses it shows an NCBI prompt to use instead.
