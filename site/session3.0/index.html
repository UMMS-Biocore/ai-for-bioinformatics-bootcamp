Session 3.0 · Pre-work

Install a terminal agent before Friday.

In 3.1 you build a knowledge base with an AI agent that works on files on your own computer, so it will not run in Claude or ChatGPT in the browser. Do this page before class: install Claude Code or Codex CLI, install Paperclip, and check that the agent answers. It takes about 20 minutes.

Stuck? Email biocore@umassmed.edu → macOS or Windows · Your own computer, with permission to install software

Set up

If anything below fails to install, or your computer does not let you install software, contact us at biocore@umassmed.edu before Friday. We would rather sort it out this week than in class.

Check what you need

  • A paid Claude or ChatGPT subscription. Free plans do not include the terminal agents.
  • One terminal AI agent, your choice: Claude Code or Codex CLI. The next steps install it.

Open a terminal

macOS: press Cmd+Space, type Terminal, and press Enter.

Windows: click Start, type PowerShell, and press Enter.

Paste each command below into the terminal and press Enter.

Install Claude Code or Codex CLI

You only need one of the two agents.

Claude Code, macOS:

curl -fsSL https://claude.ai/install.sh | bash

Claude Code, Windows PowerShell:

irm https://claude.ai/install.ps1 | iex

Codex CLI, macOS:

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Codex CLI, Windows PowerShell:

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Install Paperclip, the scientific paper index

Paperclip gives your agent search and retrieval over more than 8 million papers. First create a free Paperclip account. Then install it.

macOS:

curl -fsSL https://paperclip.gxl.ai/install.sh | bash

Windows: Paperclip has no Windows installer yet, so install it with Python.

  1. If you do not have Python, install it from python.org. On the installer’s first screen, tick Add python.exe to PATH. Then close PowerShell and open a new one.
  2. Paste these three lines into PowerShell:
Invoke-WebRequest https://paperclip.gxl.ai/paperclip.whl -OutFile "$env:TEMP\gxl_paperclip-0-py3-none-any.whl"
python -m pip install --no-deps "$env:TEMP\gxl_paperclip-0-py3-none-any.whl"
python -m pip install requests click pyyaml
  1. Close PowerShell and open a new one, so it finds the new paperclip command.
WHY Why three lines instead of one?
The download is a standard Python package, but its file name is too short for Python’s installer to accept, so the first line saves it under a name it will take. The second line installs Paperclip, and the third installs the three packages it needs. This is the same thing the macOS installer does.

Both: set Paperclip up for your agent. It asks you to sign in with the account you just made.

paperclip install

Checkpoint paperclip config shows your email next to Auth.

NO PAPERCLIP? If Paperclip will not install, you can still do the exercise
Paperclip makes the literature search better, but the exercise does not depend on it. If it will not install, skip it: in 3.1 you will have your agent search NCBI (PubMed and PubMed Central) directly instead, which needs no install and no account. Each step that uses Paperclip shows the prompt to use instead. Still let us know at biocore@umassmed.edu, so we can help you get it working.

Start your agent and log in

From the terminal, type claude for Claude Code or codex for Codex CLI, press Enter, and follow the login instructions.

Check that it works

Type this and press Enter:

What can I do with coding agents?

Checkpoint The agent answers in the terminal. If it does, you are ready for Friday. Type /exit (Claude Code) or press Ctrl+C twice to leave.
