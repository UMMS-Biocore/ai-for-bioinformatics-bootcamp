Session 4.0 · Pre-work, about 15 minutes

Get the notebooks running before Friday.

Session 4 is taught from four marimo notebooks: Python notebooks that run in your browser and rerun every cell that depends on the one you change. One small tool, uv, installs Python, marimo, and every package the notebooks need.

Stuck? Email biocore@umassmed.edu → macOS or Windows · Your own computer, with permission to install software

Set up

Can’t install software on your computer? Come anyway. Manuel runs every notebook live, and you can follow on the projector.

Open a terminal

macOS: press Cmd+Space, type Terminal, and press Enter.

Windows: click Start, type PowerShell, and press Enter.

Paste each command below into the terminal and press Enter.

Install uv

macOS:

curl -LsSf https://astral.sh/uv/install.sh | sh

Windows PowerShell:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Then close the terminal and open a new one, so it finds the new uv command.

Download the notebooks

Open the course repository, click the green Code button, and choose Download ZIP. Unzip it somewhere you can find it, such as your Desktop.

If you already use git, clone it instead:

git clone https://github.com/UMMS-Biocore/bootcamp-bulk-rnaseq.git

In the terminal, move into the folder. For a ZIP unzipped to the Desktop:

cd ~/Desktop/bootcamp-bulk-rnaseq-main

Open a notebook

uvx marimo edit --sandbox 02_ttest_is_lm.py

The first run takes a minute or two while uv downloads Python and the packages listed at the top of the notebook. marimo then opens the notebook in your browser.

Checkpoint The notebook shows figures and a table of coefficients, with no red error boxes. Notebook 2 uses only simulated data, so it needs no downloads. If it runs, you are ready for Friday. Press Ctrl+C in the terminal to stop marimo.

WHY Why --sandbox?
Each notebook lists the packages it needs in its first lines. With --sandbox, uv builds a private environment from that list, so nothing you install here touches any other Python on your computer.

Optional: open notebook 1

uvx marimo edit --sandbox 01_distributions.py

On its first run it downloads a public microarray dataset from GEO (GSE8658, about 8 MB) into the data/ folder, so do this once on a good connection.
