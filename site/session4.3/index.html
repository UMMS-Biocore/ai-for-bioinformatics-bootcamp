Session 4.3 · Homework

One model for a two-factor experiment.

Mouse liver lacking JNK1, JNK2, or both, on chow or a high-fat diet. You analyse it two ways, with one DESeq2 model that has interaction terms and with the classical route of many pairwise tests and k-means, and test the paper’s claim about PPARα targets.

Open the homework → A marimo notebook · PyDESeq2 or DESeq2 in R

The study

Vernia et al. (2014), The PPARα–FGF21 hormone axis contributes to metabolic regulation by the hepatic JNK signaling pathway, Cell Metabolism 20:512–525. GEO GSE55190.

FactorLevels
genotypeWT (Alb-Cre), Jnk1_LKO, Jnk2_LKO, Jnk1_Jnk2_LKO (liver knockouts)
dietchow, HFD (high-fat diet, 16 weeks)
replicates3 mice per genotype and diet, 24 samples

The paper’s claim: hepatic JNK represses PPARα, so JNK-deficient liver expresses more PPARα targets (fatty-acid oxidation, ketogenesis, Fgf21), especially on the high-fat diet. You will test it.

WHY Why not use the counts from GEO?
GEO has only Cufflinks FPKM for this study, which cannot be turned back into read counts, and the recount3 counts are broken for 10 of the 24 samples. So the raw reads were downloaded from ENA and quantified again with Salmon against GENCODE mouse M36. The PIPELINE.md file in the homework data folder records every step and script.

What you do

The full instructions and questions are in the homework README.md. Use FDR < 5%, and keep genes whose highest genotype-and-diet group mean is at least 3 TPM.

  1. Library sizes, depth normalization, replicate scatters, and variance against mean.Notebooks 1 and 4
  2. Fgf21, chow against HFD in WT: a t-test and y ~ diet give the same answer.Notebook 2
  3. DESeq2 on the six WT mice: which genes respond to the diet?WT only
  4. One model for all 24 samples, ~ genotype + diet + genotype:diet, with genes classified by which knockouts change them.The model
  5. Seven pairwise tests against WT chow, then k-means, compared with the model.The classical way
  6. Observed against predicted counts, with and without the interaction.Does it fit?

Start

Open the starter notebook

Open a terminal and go to the notebook folder you set up in 4.0. No homework folder in it? The homework was added on October 8, so download the notebooks again; it is safe to rerun.

macOS:

cd ~/Documents/bootcamp/session4/bootcamp-bulk-rnaseq-main

Windows PowerShell:

cd (Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'bootcamp\session4\bootcamp-bulk-rnaseq-main')

Then, on either system:

uvx marimo edit --sandbox homework/hw_starter.py

The starter notebook loads the counts and sample table and sets WT and chow as reference levels. Hand in a marimo notebook with a markdown cell before every code cell, your figures and tables, and a few sentences for each question.
